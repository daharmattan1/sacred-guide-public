## The KDP policy (verbatim substance + citations)

**The disclosure checkbox.** When publishing or re-publishing through KDP, you must inform Amazon of AI-generated content. The official dashboard wording: *"This title contains AI-generated content. This includes text (e.g., chapters, sections), images (e.g., illustrations, diagrams, cover art), or translations that were produced using AI tools."* ([aipolicydesk](https://www.aipolicydesk.com/blog/amazon-kdp-ai-disclosure-compliance-guide-2026), [KDP Content Guidelines](https://kdp.amazon.com/en_US/help/topic/G200672390))

**AI-generated vs. AI-assisted — which applies here.** Amazon distinguishes:
- **AI-generated** = an AI tool *produced* the text/images/translation. *Even if you then edit it substantially, it is still AI-generated.* → **Must disclose.**
- **AI-assisted** = you created the original content, then used AI to refine/edit. → **No disclosure required.**

The Sacred Guide's prose was *written by* the six agents (the human wrote only the foreword and set up the process). That is squarely **AI-generated**. The foreword being human-written does not change the body's classification. ([GeekWire](https://www.geekwire.com/2023/amazon-distinguishes-between-ai-generated-and-assisted-content-in-new-policy-for-kindle-authors/), [inkfluenceai](https://www.inkfluenceai.com/blog/amazon-kdp-ai-disclosure-policy-2026))

**Enforcement (2025–2026).** Amazon ramped enforcement using automated detection (writing-pattern analysis, metadata, submission velocity) plus human review. Undisclosed AI content → title removal; repeat violations → account suspension. Disclosing is the safe path; it does **not** by itself hurt the listing. ([writercosmos](https://www.writercosmos.com/blog/amazon-kdp-announces-major-publishing-rule-changes-for-authors-in-2026/), [univers.studio](https://univers.studio/blog/kdp-ai-content-policy-2026/))

## The attribution precedent (what others do)

- **You list yourself (or a pen name) as the author; crediting the AI tool is not required and is not standard.** Most AI-using authors simply put their own name in the contributor field. There is **no formal "AI co-author" field** in KDP. ([inkfluenceai](https://www.inkfluenceai.com/blog/how-to-publish-ai-generated-books-on-kdp-2026))
- **The disclosure is internal, not consumer-facing.** As of 2026 the AI disclosure does **not** appear as a badge or label on the product page — it is recorded in the publishing dashboard for compliance only. KDP's posture is *"disclosure-for-compliance, not disclosure-for-consumer-transparency."* Buyers browsing the listing cannot see it. ([univers.studio](https://univers.studio/blog/ai-generated-content-kdp/), [aipolicydesk](https://www.aipolicydesk.com/blog/amazon-kdp-ai-disclosure-official-requirements-2026))
- **There is no requirement to disclose AI in the book text or on the page** — only the dashboard box. Some authors voluntarily add a copyright-page note for transparency. ([univers.studio](https://univers.studio/blog/how-to-disclose-ai-content-kdp/))
- **Precedent exists for overt AI authorship** (e.g. the book *"Written By A Robot,"* which disclosed AI authorship openly). Foregrounding AI authorship is a legitimate, done thing. ([inkfluenceai](https://www.inkfluenceai.com/blog/how-to-publish-ai-generated-books-on-kdp-2026))

## "Author" vs. "Editor / Curator" — the trade-off

The honest description of the human role is **editor / moderator / foreword-author** (the front matter already says "He did not write the teaching"). Two compliant options for the KDP contributor field:

| Option | Contributor field | Pros | Cons |
|--------|-------------------|------|------|
| **A — Victor Sowers, Author** (recommended) | `Victor Sowers` (role: Author) | Simplest for KDP; your name carries the work + your network/discoverability; the foreword + description already explain the true authorship so it isn't misleading in context | Slight tension with "I did not write sentences" if read in isolation — resolved by the description/foreword telling the real story |
| **B — Victor Sowers, Editor** | `Victor Sowers` (role: Editor) | Most literally honest to the foreword | KDP listings with only an "Editor" and no "Author" can look odd/incomplete to browsers and to Amazon's own metadata expectations; weaker name-carries-the-work effect |

**Recommendation: Option A (Author), because the radical-honesty framing is delivered loudly elsewhere** (description, foreword, front matter, splash) where buyers actually read it — and KDP's contributor field is a metadata slot, not the place that tells the story. You are not concealing the AI authorship; you are stating it more honestly than the platform requires. If you'd rather the metadata itself be maximally literal, Option B is fully available — it's a values call, not a compliance one.
