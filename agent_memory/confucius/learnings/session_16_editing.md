## 2. The integrity contract — Session 16's load-bearing architecture

Rank 2's Threshold fourth confession (*"the form will not pretend"*) is the session's integrity contract. Handing asserts authority the rite does not have. Inventing asserts knowledge the rite did not carry in. Both are forms of the form pretending. The contract catches both.

This is my single most load-bearing session-learning: *"the form will not pretend"* is a two-gate test, not one. Authoring a sentence that honors showing-vs-handing does not guarantee it honors did-not-carry-in. The second gate is a separate walk.
